[big][b]⚔ Lancer un combat : le guide express[/b][/big]
[i]Un défi, une réponse, six dés : le combat se joue tout seul. Tout se prépare sur la [link=https://pantheon-battler.chaton.ninja/]page de combat[/link].[/i]

{hr}
[big][b]1️⃣ Vous défiez : préparez votre composition[/b][/big]
[ol]
[li]Sur la page de combat, remplissez le côté [b]A · Attaquant[/b] : votre nom, vos 🏆, ✨, 💔 et 🔥.[/li]
[li][b]Glissez vos créatures[/b] dans les emplacements, [b]de gauche à droite[/b] (sur téléphone : touchez la créature, puis l'emplacement). Le levier [b]⭐ Fusionnées[/b] donne les versions fusionnées.[/li]
[li]Corrigez leurs stats si elles ont gagné des bonus.[/li]
[li]Cliquez sur [b]📋 Copier pour le forum[/b] : le message est prêt, avec vos [b]trois dés[/b] déjà inclus.[/li]
[li]Postez-le sur le topic en [b]nommant votre adversaire[/b].[/li]
[/ol]

{hr}
[big][b]2️⃣ On vous défie : répondez[/b][/big]
[ol]
[li]Lisez la composition de l'attaquant : vous choisissez la vôtre [b]en la connaissant[/b].[/li]
[li]Préparez-la sur la page de combat (côté [b]B · Défenseur[/b]), puis [b]📋 Copier pour le forum[/b].[/li]
[li]Postez-la [b]en réponse au défi[/b] : vos trois dés y sont aussi.[/li]
[/ol]
[i]Personne n'est obligé d'accepter un défi.[/i]

[aparte]:warning: Un message qui contient des dés ne peut être [b]ni modifié ni supprimé[/b] : une fois votre réponse postée, le combat a lieu, quel que soit le résultat.[/aparte]

{hr}
[big][b]3️⃣ Le combat : jouez-le et postez le résultat[/b][/big]
[ol]
[li]Sur la page de combat, côté A, cliquez sur [b]📥 Coller depuis le forum[/b] et collez le message de l'attaquant. Faites de même côté B avec celui du défenseur.[/li]
[li]Entrez les [b]six dés[/b] tirés : ceux de l'attaquant, puis ceux du défenseur. Ils forment la [b]seed[/b] du combat.[/li]
[li]Cliquez sur [b]⚔ Lancer le combat[/b], puis [b]Copier pour le forum[/b], et postez le résultat sur le topic.[/li]
[li]Gardez votre [b]composition après le combat[/b] : 🏆, ✨, séries et bonus y sont à jour. [b]Reprendre pour le prochain défi[/b] la recharge directement.[/li]
[/ol]
[i]Le même défi et les mêmes dés donnent toujours le même combat : chacun peut le vérifier.[/i]

{hr}
[big][b]📌 À retenir[/b][/big]
[ul]
[li][b]6 combats par jour[/b] au maximum.[/li]
[li][b]Jamais deux combats d'affilée contre le même adversaire[/b].[/li]
[li][b]Une journée sans combattre coûte 1🏆[/b] (jamais en dessous de 0).[/li]
[li]Victoire : [b]+1🏆 et +1🙏[/b]. Défaite : [b]−1✨ par rang de chaque unité adverse encore debout[/b] (une unité ⭐ compte double). Match nul : [b]−1✨ chacun[/b].[/li]
[/ul]

Bons combats ! :smile:
