    Créer la réserve partagée

    Une seule fois, par un seul MJ. La réserve est un Gist secret sur GitHub : chaque MJ y écrit son propre journal, rien ne s'écrase.

    1. Connectez-vous au compte GitHub qui gardera la réserve. Un compte réservé aux MJ est plus sûr : le jeton peut modifier tous les Gists de ce compte.
    2. Créez un jeton (« classic ») avec seulement la case gist cochée, et une expiration après la fin de l'événement.
    3. Collez-le ci-dessous. La réserve déjà tenue dans ce navigateur devient la réserve partagée.

    Comment ça marche

    • Chaque navigateur écrit ses actions dans son propre fichier du Gist ; la réserve est recalculée à partir des journaux de tous les MJ. Deux MJ peuvent travailler en même temps.
    • La page se synchronise toutes les 20 secondes et à chaque action. Hors ligne, les actions attendent et partent dès que la connexion revient.
    • Le jeton reste dans ce navigateur et n'est envoyé qu'à GitHub. L'historique complet reste visible dans les révisions du Gist.
